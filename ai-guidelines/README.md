# Dokumentasi AI Agent - Sistem Prediksi Risiko Diabetes

## Identitas Proyek

**Nama Sistem:** Sistem Prediksi Risiko Diabetes Menggunakan Logistic Regression  
**Studi Kasus:** Klinik Pratama Bina Sehat Insani  
**Platform:** Website  
**Framework:** Laravel 13, Livewire 4.3 SFC, Tailwind CSS 4  
**Database:** MySQL  
**Machine Learning:** Python, Scikit-Learn, Logistic Regression  

## Tujuan Dokumentasi

Dokumentasi ini digunakan sebagai panduan untuk AI Agent, Copilot, atau developer dalam membangun sistem secara konsisten. Seluruh pengembangan harus mengikuti alur sistem, rancangan database, desain antarmuka, serta tahapan pekerjaan yang telah ditentukan.
